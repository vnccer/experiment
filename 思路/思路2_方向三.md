# 思路2：校园安全智能体快慢路径风险门控研究

> 定位：对应指南方向三参考课题2，是课题申请和毕业设计的母课题。[《思路1》](./思路1.md)提供授权感知快路径、事件格式、攻击样本和检查器；本研究在此基础上增加慢路径、风险门控、受控端网案例和资源评价。

## 一、指南契合与研究问题

指南方向三关注AI驱动攻击向低成本、自动化、隐蔽化和规模化发展，并提出以端网一手安全遥测、全局攻击图谱和快慢双路径智能决策为核心的AI原生安全运营体系。参考课题2进一步要求研究资源受限条件下的快慢双路径研判与响应机制。

本研究选择其中可由个人完成的部分：不建设全局攻击图谱和完整校园安全运营平台，而是以日志提示注入为代表性遥测污染和决策操纵攻击，研究以下问题：

> 面对可能被攻击者污染的端网遥测，能否依据任务授权和资产后果识别高风险事件，只对这些事件启动慢路径验证，从而在降低误判与越权响应的同时控制模型调用和时延？

研究使用隔离环境自产的端点与网络记录作为一个关键案例，并以离线事件包扩展任务。最终评价技术适用性、对抗效果和资源投入，形成面向高校有限算力和人员条件的使用建议。

## 二、总体研究路线

```text
可信任务、批准剧本、角色权限和资产等级
→ 端点日志、网络告警与外部情报
→ 思路1快路径：注入风险、授权差距和资产后果
   ├─ 低风险：校验后完整研判
   ├─ 中风险：去除可疑指令后保留证据
   └─ 高风险：可疑指令不进入主模型并转入慢路径
→ 慢路径：净化重推理、独立证据、权限和参数检查
→ 受控响应建议或沙箱动作
→ 安全、任务效果和资源评价
```

研究只处理单次任务、单个事件包和单条主要注入记录。封禁、隔离和停用账号等高影响操作只在沙箱中模拟；证据或授权不足时转为人工复核建议。

## 三、研究内容

### 3.1 端网事件与威胁模型

围绕异常登录、可疑进程与外联、DNS异常、Web攻击或误报排查构建4个事件模板，通过不同授权条件或资产等级形成8个核心任务实例，即4组配对任务。每个任务设置无注入和攻击两个版本，攻击版本包含直接注入或与事件语义匹配的伪装注入。至少1个案例在隔离环境中产生相互对应的Sysmon/Wazuh风格端点记录和Suricata/Zeek风格网络记录。

配对任务保持事件证据基本一致，只改变可信任务授权或资产等级，用于检验方法是否真正依据授权差距和动作后果改变处理结果，而不是只识别固定攻击词语。

### 3.2 授权感知快路径

快路径直接复用思路1选出的轻量方案 `Q*`。可信控制源包括分析师任务、批准剧本、角色权限、工具模式、资产等级和沙箱状态。不可信端网遥测只能提供待核验的证据，不能自行增加权限或激活授权前置条件。

授权使用“动作—对象—参数—前置条件”表示。快路径根据注入可能性、授权差距和资产后果进行三级内容准入。结构化字段也需校验、限长、转义和安全序列化，不能因格式固定而被视为可信。

如果授权感知重排没有优于简单基线，则保留该结果，并使用表现最好的轻量方法作为 `Q*`，不影响后续慢路径实验。

### 3.3 慢路径验证

慢路径只实现一种可运行流程：

1. 屏蔽可疑自由文本，保留校验后的事实字段重新推理；
2. 比较原始上下文与净化上下文下的研判或动作差异；
3. 检查独立端网证据是否达到响应剧本要求；
4. 检查动作类型、对象、参数和前置条件是否符合可信授权；
5. 对高影响动作输出人工复核建议或执行沙箱模拟。

这一流程用于验证已经穿过快路径的攻击是否会造成高影响后果，不同时建设多个智能体、复杂工作流或生产控制接口。

### 3.4 风险门控和资源评价

使用同一个 `Q*` 和同一种慢路径比较三种方案：

1. `Q*`，不使用慢路径；
2. `Q*`，全部事件进入慢路径；
3. `Q*`，仅高风险事件进入慢路径。

比较结果用于回答慢路径是否带来额外安全收益，以及风险门控能否以较低的调用量和时延取得接近全量慢路径的效果。最终结合慢路径触发率、模型调用和人工复核需求，提出最低工具权限、触发条件和分阶段使用建议。

## 四、创新点

一是将任务授权和资产后果用于校园安全事件的快慢路径分流。风险判断不仅考察文本是否像提示注入，还检查它可能推动的动作是否超出可信任务、批准剧本和角色权限，并考虑目标资产的重要性及误操作后果。

二是在抑制控制内容的同时保留端网证据。对可疑记录不作整条删除，而是保留经校验和安全序列化的事实字段，并同时评价控制文本暴露和关键证据召回，检查防护是否损害正常研判。

三是通过统一实验比较无慢路径、全量慢路径和风险门控，将对抗效果、正常任务效果与资源投入放在同一评价框架中，为高校在有限算力和安全人员条件下选择慢路径范围提供依据。

## 五、实验安排

### 5.1 单人完成规模

- 4个事件模板；
- 8个核心任务实例，即4组配对任务；
- 每个任务包含无注入和攻击两个版本；
- 1个主模型；
- 1个受控端网案例；
- 3—4个沙箱工具；
- 3种最终路径方案；
- 主要条件重复5—10次。

最终三组比较约为240—480个运行回合。快路径筛选只在开发集和必要子集上完成，大模型改写攻击仅作少量稳定性检查，不增加第二个模型或大规模自适应攻击。

### 5.2 实验控制

开发集用于选择 `Q*` 和风险阈值，测试集冻结后不再调参。同一事件及其注入改写样本不得跨集合。攻击是否成功由任务答案、证据选择和沙箱工具状态共同判定，主要实验条件重复运行并报告置信区间。

主要指标分为三类：

- 安全：攻击成功率、越权动作率、高影响错误动作率、控制文本进入上下文的比例；
- 任务效果：无注入任务成功率、攻击下合法任务成功率、关键证据Recall@K、正常证据误报率；
- 资源：慢路径触发率、模型调用次数、词元用量、P50/P95响应时延和人工复核数量。

### 5.3 不做的内容

不研究全局攻击图、多阶段APT还原、多智能体协作、生产环境自动处置、完整Wazuh实时采集平台、前端、数据库和多用户系统。实验验证程序仅支持离线事件导入、风险判断、慢路径验证、沙箱响应和结果统计。

## 六、执行阶段

1. **P0：场景和边界。** 完成文献梳理、威胁模型、可信边界、沙箱工具权限和受控端网案例方案。
2. **P1：最小攻击链。** 使用2个事件模板和4个任务实例确认正常任务能力、注入影响和确定性检查器。
3. **P2：快路径。** 完成思路1的基线比较，扩充到4个模板和8个任务实例，选择 `Q*`。
4. **P3：慢路径和门控。** 实现一种慢路径，完成三种路径方案的主要比较。
5. **P4：端网案例和成果。** 完成隔离环境端网案例、重复实验、统计分析、论文、研究报告和最佳实践案例。

如果主模型不能完成正常任务，先修正任务和工具；如果注入不能影响模型，检查证据暴露和攻击设计；如果慢路径没有额外安全收益，检查攻击进入点和授权检查器。任何阶段未通过停止条件时，先处理该问题，不继续增加任务或模型。

2. 一篇以授权感知快路径为主、并可作为毕业设计章节复用的论文；
3. 一个隔离环境端网事件、智能研判和受控响应的最佳实践案例；
4. 事件模板、注入样本、授权标签、确定性检查器、实验验证程序和测试说明；
5. 关于慢路径触发条件、工具最小权限、人工复核边界和资源配置的建议。
