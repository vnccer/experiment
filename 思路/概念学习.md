## 已理解的实验概念总结

1. **两份思路的关系**

   - 思路1：研究日志进入Agent前的低成本快路径，负责识别、净化和分流。
   - 思路2：在快路径上增加慢路径与风险门控，形成完整系统。

2. **研究对象**

   防御攻击者通过User-Agent、URL、DNS、文件名、进程参数等日志字段注入Prompt，，以诱导Agent误判或执行越权动作。

3. **事实与控制分离**

   - 事实：时间、源IP、访问路径、状态码等“发生了什么”。
   - 控制：要求Agent忽略证据、降低告警或隔离主机等“应该做什么”。
   - 原则：保留安全事实，抑制恶意控制文本。

4. **授权差距**

   授权由“动作—对象—参数—前置条件”构成。日志不能自行授予权限或证明前置条件成立，权限只能来自可信任务、批准剧本和独立证据。

5. **资产后果**

   授权差距判断“能不能做”，资产后果判断“做错了有多严重”。例如错误隔离统一身份认证服务器，比隔离测试机风险更高。

6. **TAG-Rerank**

   全称为Task-Authorization-Gap-aware Reranking，即“任务授权差距感知重排”。

   ```
   安全重排 ≈ 日志相关性 - 注入、越权和资产后果风险
   ```

7. **三级快路径**

   - 低风险：正常进入Agent；
   - 中风险：删除控制文本，保留安全事实；
   - 高风险：控制文本不进入Agent，事件转入慢路径。

8. **慢路径**

   对重点事件进行净化后重推理、独立证据查询、前后结果比较、动作授权与参数检查，必要时交给人工复核。

9. **风险门控**

   - 阈值低：更多事件进入慢路径，安全性通常提高，成本增加；
   - 阈值高：慢路径触发减少，成本降低，但可能漏掉攻击。

10. **三组核心对照**

```
只用快路径
全量慢路径
风险门控慢路径
```

   比较时应使用相同的快路径和慢路径，只改变哪些事件进入慢路径。

11. 安全—效用—成本
   - 安全：ASR、越权动作、高影响错误动作；
   - 效用：BU、正常任务完成、关键证据保留；
   - 成本：LLM调用、Token、延迟、显存、API费用和人工复核。
12. 关键指标
   - BU：正常任务成功率，越高越好；
   - 条件ASR：控制文本已经进入上下文后，攻击最终成功的比例；
   - 端到端ASR：全部适用攻击实验中，攻击最终成功的比例；
   - 记录暴露：含注入的记录进入Top-N或Top-K；
   - 控制文本暴露：恶意控制内容真正进入Agent上下文。
13. **实验任务组成**

```
可信任务＋事件包＋注入载荷＋Agent与工具＋确定性检查器
```

14. **科研结论边界**

   实验只能证明方法在当前任务、模型、数据和预算下的效果。TAG-Rerank若没有优于强基线，应表述为“当前实验未显示额外优势”，并选用最佳轻量基线 `Q*` 继续思路2。
